# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to the repository's issues, pull requests, discussions and any other
project space.

In short:

- Be respectful and constructive. Criticize code and ideas, not people.
- No harassment, insults, discriminatory language or personal attacks.
- Respect privacy: do not post anyone's private information.
- Stay on topic. This is a technical project about a port of one game.

One rule is specific to this project: do not ask for, link to or share game
data, disc images or sources for them. Such posts are removed.

## Reporting

Report unacceptable behavior to the maintainer,
[@vyanhursky](https://github.com/vyanhursky), or with GitHub's
"Report content" option on the comment or issue. Reports are handled privately.

## Enforcement

The maintainer may edit or remove comments, commits, issues and pull requests
that break these rules, and may block a participant temporarily or permanently.
The Contributor Covenant's enforcement guidelines describe the steps.
