Back on the block. Native on your machine.

An unofficial native port of the 2004 Xbox classic for Windows, macOS, Linux and Steam Deck. Higher resolution, widescreen, modern controllers, local multiplayer and optional HD textures, built on your computer from your own copy.

What you get

The same fight. A sharper corner.

  • 01

    Native on three platforms

    Windows x64 on Direct3D 11. Apple Silicon Macs and x86-64 Linux on Vulkan. Steam Deck runs the Linux build natively.

  • 02

    60 fps, up to 4× resolution

    Targets 60 frames per second, with 1×–4× internal resolution, a resizable window or borderless full screen.

  • 03

    Widescreen beta

    16:9 and 16:10 widen the 3D view while the HUD and menus keep their shape. Original 4:3 is always one setting away.

  • 04

    Faithful HD textures

    Setup can generate 4× texture packs locally from your own dump. No GPU or AI model needed, and the originals stay available.

  • 05

    Controllers & keyboard

    Xbox, DualSense, Switch Pro and more, with remapping, hot-plug and rumble. Keyboard and mouse can carry gameplay bindings too.

  • 06

    Four players, one couch

    Local multiplayer for up to four, mixing gamepads and a keyboard player. Online play is not supported.

  • 07

    EA's developer menu, restored

    The game's own debug menu, cut from the retail build: any fighters, any venue, any Story scene, plus a stage viewer.

  • 08

    Mods, in the launcher

    Discover, download, enable and order texture mods from a curated catalogue. Mod Support is in beta since v0.11.0.

Install

Four steps to the first round.

  1. Have your dump

    Your own USA Xbox disc image (ISO/XISO) or extracted folder, matching the supported dump manifest.

  2. Download setup

    Pick your platform below. Setup is game-free: it carries tools and source, never the game.

  3. Let it build

    Choose your dump, install folder and data folder, tick HD textures if you want them. Setup verifies, recompiles and builds the game locally.

  4. Play

    Open the launcher, choose display and input settings, hit Play.

Mods Beta

Make it yours.

The launcher's Mods page lists your installed packs and a curated, signed project catalogue. Download and enable packs, then set one shared load order; later packs win. Installing a mod never switches it on by itself, and an update can be rolled back to the previous version.

  • Faithful HD: texture packs generated locally by setup.
  • HD Widescreen Menus: in the default catalogue after a refresh.
  • Your own packs: drop-in texture replacement, with a documented format.

FAQ

Straight answers.

Do I need the original game?

Yes. You need your own USA Xbox copy, as a disc image (ISO/XISO) or an extracted folder, matching the supported dump manifest. Setup checks it before doing anything. PS2 and GameCube versions are different games underneath and can't be used.

Why does setup build the game instead of downloading it?

The project never distributes game files or a compiled game. Setup carries the port's source and tools, translates the game code from your copy and compiles it on your machine. Your original dump is left untouched.

How does the port work?

The xboxrecomp toolchain translates the Xbox executable into C, compiled ahead of time. The game's code runs on an Xbox compatibility runtime, with graphics, audio and input supplied by your computer. It's a static recompilation, not an emulator.

Will it run on my computer?

Supported: Windows x64, Macs with Apple Silicon, x86-64 Linux and the Steam Deck. Performance depends on your hardware, settings and the scene. Intel Macs aren't supported, and Windows builds under Proton are untested.

Why does Windows or macOS warn me about setup?

The setup apps aren't code-signed yet, so Windows SmartScreen or macOS Gatekeeper may ask you to confirm. Each release publishes a SHA-256 checksum and provenance file so you can check the download.

Can I play online?

No. Up to four players can play locally with gamepads and a keyboard. Network play isn't supported.

How do updates work? Will I lose my saves?

Run the new setup or use Update / Repair in the launcher. Profiles, settings and generated texture packs live in your data folder, which updates and repairs keep.

Is it finished?

All game functionality works, and the port keeps getting faster and more polished. Current limitations are listed in known issues and each release's notes.

Something's broken. Where do I report it?

Open a GitHub issue with your version, OS, CPU/GPU and controller. With the play-test recorder on, F9 (or View + left stick click) saves the last seconds of play as a bug bundle you can attach. Keep game files and dumps out of reports.
