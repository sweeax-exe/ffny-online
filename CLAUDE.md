# Claude Code notes

Everything above is the shared instruction set (`AGENTS.md`, which Codex reads directly). Edit that file, not this
one. This file holds only what applies to Claude Code.

- **Sub-agents.** Spawn a delegated reading task with `subagent_type: general-purpose`, `model: sonnet`, in the
  background, and keep working meanwhile. The project agents `re-reader` (Sonnet) and `log-triage` (Haiku) in
  `.claude/agents/` run the briefs in `docs/agent/briefs/`; they do not load these instructions, so the brief
  carries what they need. Use `log-triage` for bounded independent reading when the digest alone does not settle a run
  and the delegation criteria apply; keep stateful diagnosis and the build/run loop with the main agent. `.claude/skills/` (`triage-run`, `drive-game`, `bringup-iteration`) and
  `.claude/agents/` are generated by `python scripts/sync-agent-adapters.py`; edit `docs/agent/`.
- **The Bash tool collapses `\\` to `\`.** Use raw Python strings or forward slashes when writing Windows paths from a
  heredoc, or use the Edit/Write tools for files with backslashes. The same collapsing eats `\n` inside a C string
  literal written from a heredoc, which the compiler then reports as "newline in constant". Write the script to a
  file in the scratchpad and run it, or build the escape as `chr(92) + 'n'`.
- **Large tool results.** A run log, a CI job list or a full `pytest` traceback can be tens of thousands of tokens.
  Use `scripts/triage.py` slices for logs, ask for one failing job's log rather than listing every job, and run
  `pytest -q -m "not slow"` while iterating.
