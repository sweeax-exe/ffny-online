# README gameplay visuals

vyanhursky supplied and explicitly approved these visuals for the public README on
October 4, 2026 (D58):

- `fight-screenshot.png`: the supplied Windows gameplay screenshot, unchanged.
- `fight-gameplay.gif`: the supplied six-second gameplay recording, converted
  to a looping, silent GIF at 480 pixels wide and 12 fps. The window title bar

choice, not a measurement of game performance. Game artwork remains the
property of its respective rights holders; the project MIT license does not
apply to it.
