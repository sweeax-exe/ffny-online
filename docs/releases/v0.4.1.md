# v0.4.1 — xboxrecomp v0.13.0 migration

This source release updates the pinned xboxrecomp fork to upstream v0.13.0,
preserving Def Jam's display, audio, controller, save, launcher and overlay support.

## Changes

- Rebase the retained Def Jam toolkit changes onto upstream v0.13.0. Four patches
  already supplied upstream are omitted; the remaining 22 topics are retained.
- Preserve parity and floating-point comparison flags across control-flow joins,
  and include slot zero when recovering backward switch tables.
- Clear x87 C2 after a completed remainder operation, allowing guest CRT polling
  loops to finish after a floating-point classification.
- Share synchronization-event consumption between single and multiple waits and
  report live contiguous and heap allocation statistics.
- Publish AC97 trap ownership before protecting its page, avoiding a startup
  window in which another thread could fault before the handler recognized it.
- Run compiled recompiler fixtures with MSVC on Windows and expand hosted native
  fixture coverage, including the slow counter-wrap regression.

New upstream heap-reclaim and extended-memory modes remain disabled by default.
The simulation and image goldens and their comparison thresholds are unchanged.

## Build this version

```powershell
git clone --recursive --branch v0.4.1 https://github.com/vyanhursky/DefJamFFNY-recomp.git
cd DefJamFFNY-recomp
```

Follow [Build and play](../build-and-play.md) with your own supported USA Xbox dump.
When updating an existing checkout, update submodules, then rerun analysis,
recompilation and the Release build; generated code from v0.4.0 must be regenerated:

```powershell
git submodule update --init --recursive
.\scripts\analyze.ps1
.\scripts\recomp.ps1
.\scripts\build.ps1 -Preset win-x64-release
```

This is a source release. No game data, generated guest code or executable is included.
The first configure needs network access for the pinned SDL3 and Dear ImGui sources.

## Validation

The owner play-tested the candidate Release build on October 8, 2026, reported
"It plays great", and approved release.

Local Windows validation passed:

- 656 toolkit tests and 107 subtests; one explicit unsupported MSVC sanitizer skip.
- 15 native toolkit fixture projects, the AC97 startup fixture, and 173 parent unit tests.
- 5,855 real-x86 snippet vectors and 211 compiler-function vectors with zero mismatches.
- Release full regression 14/14 and all five optional checks; Debug 9/9 and a
  separate two-player check 26/26; Release quick regression 5/5.
- Release 10/10 and Debug 5/5 soak boots, with no hangs or failures.
- Keyboard input, two SDL pads, late SDL pad attachment and overlay open/close checks.
- Unchanged image goldens and replay: 80 records across 1,800 simulation steps.
- Original saves, generated files and builds preserved byte-for-byte during testing.

The automated host-input checks use virtual devices; the owner's live playtest
supplies the interactive acceptance. Hosted CI uses synthetic fixtures and builds
the runtime without game code; it does not run the game.
