# v1.0.1 — Linux ships as one AppImage

A packaging hotfix for v1.0.0. The game, the app and the setup behave as in v1.0.0; only the Linux downloads change.

As always, you need your own supported USA Xbox dump. No game files or game executables are distributed.

> **Linux and Steam Deck players: update by hand once.** The Linux app is now `DefJamRecompiled-1.0.1-linux-x86_64.AppImage`. The v1.0.0 AppImage looks for the old file name, and the v0.13.0 Linux setup looks for a setup download that no longer exists, so neither offers this update. Download the AppImage below and open it: it finds your installation and offers to update the game, keeping your saves, settings and mods. From then on it updates itself.

## Downloads

- **Windows:** `DefJamRecompiled-1.0.1-windows-x64.exe`.
- **Linux and Steam Deck:** `DefJamRecompiled-1.0.1-linux-x86_64.AppImage`. It installs, updates and adds itself to Steam, and builds the game with a toolchain it carries.
- **macOS (Apple Silicon):** `DefJamRecompiled-1.0.1-macos-arm64.zip`.
- The Windows and macOS setup tools (`DefJamSetup-1.0.1-windows-x64.exe`, `DefJamSetup-1.0.1-macos-arm64.dmg`) are attached as well. Every file has its SHA-256 and provenance.

## What changed

- **Linux ships only the AppImage (#199).** The separate Linux setup download (`DefJamSetup-<version>-linux-x64.tar.gz`) is no longer published. The AppImage carries the same setup and does everything it did.
- **The AppImage names its platform (#199):** `DefJamRecompiled-<version>-linux-x86_64.AppImage`, like the Windows and macOS files. The app and the website still recognise the old name for v1.0.0.

## Moving to 1.0.1

- **Windows and macOS, from 1.0.0:** the app offers this release as an update. Then it offers **Update game**, which builds the game again from your dump. Your saves, settings and mods are kept.
- **Linux and Steam Deck, from 1.0.0 or v0.13.0:** download the AppImage above and open it, as described at the top.

## Tested for this release

- Windows 11: unit tests (706 passed; the Linux-only ones are skipped on Windows) and the source policy check.
- CI: the Windows, macOS and Linux app and setup builds, the Linux setup's wizard smoke test and the release asset checks.
- The game itself is unchanged from v1.0.0, so the full regression was not rerun. See the [v1.0.0 notes](v1.0.0.md) for its test results and known issues.
