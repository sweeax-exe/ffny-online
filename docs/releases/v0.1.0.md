# v0.1.0 — Playable Windows source release

The first public source version of Def Jam: Fight for NY — Recompiled targets
Windows x64. The October 4, 2026 owner play-test accepted the optimized Release
build: smooth frames, much better audio and no additional graphical glitches
discovered over one hour of Story Mode playtime.

## Included

- Working menus, match setup and fights; verified Story intro/creator, crib/gym
  and Unlock Fighters routes.
- Direct3D 11 rendering with GPU vertex programs, audio and XInput controller support.
- Local profiles and read-only compatibility with earlier project save-folder hashes.
- The published xboxrecomp fork pin: 108 historical patches mapped into 15 topics.
- A launcher that supplies the required runtime defaults in a fresh shell.
- Build, test and source-release documentation and GitHub workflows.

## Build this version

```powershell
git clone --recursive --branch v0.1.0 https://github.com/vyanhursky/DefJamFFNY-recomp.git
cd DefJamFFNY-recomp
```

Follow [Build and play](../build-and-play.md), supplying your own supported USA
Xbox dump. Build and launch with `-Preset win-x64-release`. This optimized
`RelWithDebInfo` preset retains crash symbols. GitHub source ZIP/tar archives
omit submodule contents; a recursive clone fetches the exact public toolkit pin.

This is a **source release**, not a prebuilt game download. No disc images,
game assets used as build inputs, generated game C, compiled game executable
or saves are included. Two owner-approved README gameplay visuals are included;
they are presentation media and cannot be used to build or play the game.

## Validation and limits

Both game presets passed the nine-check regression; Debug passed 20/20 soak boots.
Five additional routes passed and 13 captures were reviewed. The owner's listening
and visual assessment accepted the build. Detailed evidence is in the
[rebase acceptance](../research/toolkit-rebase-acceptance.md).

Hosted CI checks source hygiene, project tests, native Release fixtures, CPU
semantics and Release runtime libraries without game data. It does not build or
play the complete game. Two-player gameplay, long-session memory, rare historical
boot/crash issues and other platforms remain [limitations](https://github.com/vyanhursky/DefJamFFNY-recomp/blob/v0.1.0/docs/known-issues.md).

PC features are next, followed by Proton/Steam Deck and macOS. Toolkit upstream
PRs require the maintainer's separate approval.
