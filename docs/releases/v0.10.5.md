# v0.10.5 — menu sound effects with *Skip startup movies*

A hotfix for the **Skip startup movies and legal screen** option added in v0.10.1. With it on, the
game started at Press Start as intended, but the menu sound effects were missing. Nothing else in
the game, the toolkit or the setups changed.

## Changes

- **Menu sound effects play with *Skip startup movies and legal screen* on**
  ([#65](https://github.com/vyanhursky/DefJamFFNY-recomp/issues/65)). The Press Start sound, the
  transition from Press Start to the main menu and the transitions from the main menu into the
  sub-menus were silent; music played. A normal start sets up the game's audio in two steps, the
  second after the startup movies end, and the option skipped that second step. It is now done
  when the option skips the movies, so the sounds match a normal start. With the option off,
  nothing changed.
- **For developers.** `regress.py --only skipintro` now checks that the audio setup is complete in
  every case with the option on, and fails on v0.10.4. `tests/unit/test_skip_intro.py` checks the
  call. The cause and trace are in
  [startup-skip-flow](../research/startup-skip-flow.md#audio-initialization-issue-65).

## Validation

- On a Mac, a capture of the game's audio output on the start-up route showed no sound at the menu
  sound events with v0.10.4 and the same sounds as a normal start with the fix. The Battle menu
  route and a One on One match played with menu and match audio, no crash, saves unchanged.
- The skip-startup regression (five cases: defaults, settings file, both overrides, combined
  unlock) passes with the fix and fails without it.
- Hosted CI builds and tests Windows, macOS and Linux. Windows and Linux were not listened to for
  this fix; the changed code is the same on every platform. The toolkit (`32aab4d`) is the same
  as in v0.10.4.

## Known limits

- The v0.10.4 limits are unchanged; see [known issues](../known-issues.md).

## Updating

- **If you use *Skip startup movies and legal screen*:** update to get the menu sounds. As a
  workaround on an older version, turn the option off.
- **If you do not:** nothing changed for you; updating installs the same game as v0.10.4.
