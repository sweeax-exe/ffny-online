# v1.1.1 — Windows update fix

Fixes an update or repair stopping with **Access is denied** while replacing
`DefJamLauncher.exe`, including the `.restore` error on a subsequent retry (#207).

An older Windows shortcut can leave its launcher running behind the app. Before
setup starts, the app now restarts directly and resumes the selected operation
after the old launcher exits. Saves, settings, mods and the verified dump are kept.
If another launcher is still open, setup reports it before recovery or compilation.

Recovery on all platforms leaves files that already match their backup alone and
reports both the original error and any rollback error. macOS and Linux already
replace their shortcut wrapper with the app, so they do not need the Windows restart.

## Downloads and updating

- **Windows x64:** `DefJamRecompiled-1.1.1-windows-x64.exe`.
- **macOS, Apple Silicon:** `DefJamRecompiled-1.1.1-macos-arm64.zip`.
- **Linux / Steam Deck:** `DefJamRecompiled-1.1.1-linux-x86_64.AppImage`.

Each package includes its SHA-256 and provenance. Releases publish the app packages
only; the legacy setup downloads remain retired. You need your own supported USA
Xbox dump; no game files or precompiled game are distributed.

Update through the app, or download the new app and open it. On Windows, if an old
shortcut is blocking recovery, close the app and any background `DefJamLauncher.exe`,
then open `DefJamRecompiled.exe` directly and select Repair / Update game.
