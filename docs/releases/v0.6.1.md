# v0.6.1 — macOS setup and HD textures on macOS

This release adds a setup installer for Macs with Apple Silicon and draws the optional
HD texture packs through Vulkan on macOS. The Windows game is unchanged. No precompiled
game, dump or generated guest code is distributed: setup compiles the game on your Mac from
your own supported USA Xbox dump.

## Changes

- **macOS setup (Apple Silicon).** `DefJamSetup-0.6.1-macos-arm64.dmg` holds a native
  wizard with the Windows wizard's steps: your ISO/XISO or extracted dump, separate install
  and data folders, an unchecked HD texture option, a desktop-shortcut choice, Install /
  Repair, logs, Play and Cancel, plus silent mode (`--silent`, `--uninstall`, `--hd-textures`)
  with the same exit codes. It needs no Terminal, Homebrew, CMake or Python of your own and
  no internet connection. See the [installer guide](../setup-installer.md).
- **Command Line Tools.** Apple's compiler cannot be bundled. If the Xcode Command Line
  Tools are missing, setup stops with exit 3 and links Apple's instructions.
- **A launcher app made on your Mac.** `Def Jam Recompiled.app` takes the play lock, supplies
  the data folder, keeps the ten newest play logs in `~/Library/Logs/DefJamRecompiled` and
  becomes the game; setup adds copies in `~/Applications` and on the Desktop and removes
  exactly those on uninstall.
- **HD textures on macOS.** The Vulkan renderer now keeps mip chains, honours the mip filter
  and uploads each level, and the pack loader runs on macOS and Linux (stb PNG decoding,
  the system SHA-256). Packs are the same files as on Windows. Without a launcher or overlay
  on macOS yet, turn them on or off with `[textures]` in `settings.ini`.
- **Bundled, pinned runtime.** Python, CMake, Ninja, SDL3, shaderc and MoltenVK (linked
  directly, no Vulkan loader) ship in the payload, each pinned by SHA-256 or commit; the
  game build ignores `/opt/homebrew` and `/usr/local`. The toolkit no longer links OpenSSL
  (it never called it) or needs pkg-config.
- **HD generation fix.** Parallel workers could write the same texture through one temporary
  file name and stop the run; each now writes through a name of its own.

## Try it

Open the disk image and open `Def Jam Setup`. The setup is **unsigned**, so macOS blocks it
the first time: choose **Done**, then System Settings → Privacy & Security → scroll to
Security → **Open Anyway**, and confirm. You do this once.

## Validation and limits

- Checked on arm64 macOS 26 with `/opt/homebrew` and `/usr/local` made unreadable: a full
  silent install from an XISO (extract, analyze, lift, compile), the launcher starting the
  game with the receipt's data folder, a repair while the game runs refused (exit 5),
  shortcuts created and removed, and the installed build passing the title, menu and
  fight checks.
- HD: the full 18,971-image pack (6,212,168,677 bytes, identical to the Windows build's)
  generates in about two and a half minutes, loads with 12-level mip chains, and the title,
  menu and a fight match the goldens with packs on, the fight holding a median of 120
  presents per two seconds. Frames were compared with packs on and off by eye.
- **Windows was not re-run for this release.** The Windows setup and game are expected to
  behave as in v0.6.0, but this release changes shared code (the setup engine and packager,
  the asset checker, the HD corpus writer and the pack loader, whose Windows code was moved
  behind a small host-services block, not rewritten). Windows CI covers the unit tests, the
  setup build and the pack fixture; a real Windows setup run follows separately.
- **Not yet validated:** a Mac with nothing installed (a clean user or virtual machine),
  macOS versions before 26, Gatekeeper's first-open prompt on a downloaded copy, a full
  setup run with the HD option from the wizard itself, and the first-time hitch when a
  texture is first shown on slower Macs.
- Still to come on macOS: the launcher and overlay (v0.6.2). Linux has no installer.
- Generated pack folders are named after the setup's HD scripts, so a setup that changes them
  makes new packs and leaves the old ones (about 6 GB each) in your data folder; delete the
  ones you no longer use from `mods`.
- The Windows setup and game are as in v0.6.0 apart from the HD generation fix above.
