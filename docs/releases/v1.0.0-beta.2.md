# v1.0.0 beta 2 — Def Jam Recompiled, the app

**This is a beta for play-testers.** It is published as a GitHub prerelease, so it is not the latest release, and the app and setup of v0.13.0 never offer it as an update. The latest stable release stays [v0.13.0](v0.13.0.md). Please play it and [report what you find](https://github.com/vyanhursky/DefJamFFNY-recomp/issues/new/choose); press **F9** in the game to save a bug bundle (a short recording and the logs) to attach.

As always, you need your own supported USA Xbox dump. The app checks it and builds the game on your computer. No game files or game executables are distributed.

Everything in [beta 1](v1.0.0-beta.1.md) is here. This beta fixes what its testers found.

## Moving from beta 1

Download this beta's app and open it.
- **Windows:** the downloaded program replaces the installed app.
- **Linux and Steam Deck:** the downloaded AppImage replaces the installed one.
- **macOS:** replace the app yourself.

The app then offers to update your game. Choose **Update game**: the game is built again from your dump, in about ten minutes. Your saves, settings and mods are kept, and beta 1 stays playable until the new build is ready.

Beta 1's app does not look for this beta itself, because both report version 1.0.0. From this beta on, the app tells builds of the same version apart.

## Fixes

- **The texture memory budget works again (#182).** Every beta 1 player ran at 512 MiB, whatever **Texture memory budget** in Mods > Advanced mods said, because the setting reached the game under a name the texture loader does not read. Scenes with upscaled or HD textures evicted and reloaded them, and the widescreen sides flashed black: Press Start to the main menu, and the stage select in Battle. The 2048 MiB default applies again, and so does your own setting. If you raised it as a workaround, it now takes effect.
- **Language mods load on Linux and the Steam Deck (#183).** The pack's name was lost at start, so the game stayed in English with a language mod on. Windows was not affected.
- **Uninstall on Linux removes the Steam shortcut (#183).** Beta 1 removed the shortcut's artwork and left the shortcut behind. If that happened to you, open **Help**, choose **Repair or rebuild...**, then **Remove from Steam** and **Add to Steam**.
- **Moving between builds of one version (#184).** A newer build of the same version replaces the installed app and offers to update the game, as described above.

Language mods are not listed in **Load Order**. That is by design: a language mod changes the game's own files beneath every texture mod, and only one is on at a time. Turn it on or off in **Installed mods**.

## Tested before this beta

- **Windows 11:**
  - The texture budget: the game reads 4096 MiB from the setting. The main menu in 16:9 with Upscaled Original Textures evicts nothing, where beta 1's 512 MiB evicted 270 textures.
  - Moving from beta 1: a scratch install of beta 1's app was replaced by this beta's app in 2 seconds. With beta 1's game installed, the app then offered **Update game**. The rebuild itself was not run in that test.
  - The unit tests.
- **Steam Deck:** the Spanish translation mod loads and the main menu is in Spanish. The Steam fix is covered by unit tests.
- **CI:** all three app and setup builds pass, along with the unit tests, native fixtures and source policy.

## Known issues

- **Learn Moves.** The Story Learn Moves list draws grey and light bars behind its rows (#181), which may or may not match the console.
- **Disk space.** Each Update or Repair keeps another ~600 MB build in the install folder (#180).
- **Under investigation:** memory growth over long sessions (#166), plain fight replays that differ on the Steam Deck (#98), and the menu and map issues #141 and #162.
- The project website (#133) is not part of this release.
