# v0.8.0 — Setup release selection and recoverable updates

The Windows, macOS and Steam Deck setup wizards can fetch stable GitHub releases,
select a compatible platform setup, and run that release's own installer engine.

## Changes

- Install, repair, clean-update and clean-rebuild from setup. Clean operations
  compile a fresh candidate from the verified installed dump without requiring
  the original disc image.
- Preserve saves, profiles, settings, caches, mods and HD texture packs.
- Verify downloaded setup checksums, provenance and payload inventory before
  handing off to the selected release's bundled Python and engine.
- Recover interrupted activation through an owned journal covering the stable
  launcher, receipts and changed settings. Optional shortcuts reconcile after
  the core installation commits.
- v0.8.0 is the first updater-capable release (U0), protocol/data schema 1.
  Downgrade is supported only between compatible updater-capable releases;
  v0.7.3 and earlier cannot be downgrade targets. Historical remote setups are
  available for fresh installation only; use their original setup for repair.

## Validation and scope

Vlad confirmed testing complete and authorized merge/release on 2026-10-12.
PR #18's pre-release head passed all 25 hosted CI jobs, including the three
platform setup packages. Recorded Mac checks include 339 passing unit tests,
ten native synthetic installer/handoff/recovery cases, interactive wizard paths,
and a disposable owner-dump install and clean update preserving 120 files.
The detailed [test ledger](../setup-update-test-results.md) retains the limits of
that evidence and historical failures. Linux updater acceptance scope is Steam
Deck/SteamOS. macOS setup remains unsigned.

The release contains game-free setups, checksums and provenance. Players supply
and compile their own dump locally. No game executable or game data is shipped.
