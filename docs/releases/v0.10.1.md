# v0.10.1 — Skip startup movies and legal screen

An optional debug setting now takes you to **Press Start** after initial loading,
without waiting through the legal screen and startup movies. Automated regression
tests use this path for most launches, saving time while retaining one complete
normal startup check in each quick and full regression set.

## Changes

- **Skip startup movies and legal screen.** Enable the checkbox under
  **General → Debug** in the launcher. It is off by default. Enabling it before
  Play applies to that launch; changing it in the in-game overlay applies on the
  next launch. The settings-file option is `[debug] skip_intro=true`, with
  `RECOMP_SKIP_INTRO=1` available for automated runs.
- **Story and attract movies still play.** The setting only skips the initial
  legal and startup-movie sequence. Controller and save checks still run when
  you press Start. Initial loading and the title screen's own animation remain.
- **Faster regression runs.** Most harness launches now skip startup movies.
  Each standard quick/full set still checks the complete legal, EA, THX and
  intro-movie sequence through Press Start once, using the existing title golden.
  Explicit normal-startup overrides remain available. Player settings are not
  changed by the harness default, and save-restoration checks remain in place.
- The debug unlock option now applies at the first main menu when startup is
  skipped. Terrordome stress routes also select and verify the actual arena
  before loading, independent of the unlocked venues' map order.

## Validation

Native play-testing on Apple Silicon macOS covers the setting and environment
overrides, launcher and overlay, Press Start and main menu, fresh saves, keyboard,
late controller connection, two players, debug unlocks, Story and attract movies.
Quick regression on the released v0.10.0 integration passes 5/5, and the final
unit run passes 470 tests. Fast startup also works with the restored Story-scene
launcher; a scene renders correctly and a short scene returns to the main menu.

The final full regression on the v0.10.0 integration completed 15/17 checks.
The only failures were the existing intermittent output-device audio queue gate:
three dry events in combat and one in versus, with zero dropped buffers. All
seven combat and six two-player gameplay assertions passed, with identical save
restoration. v0.10.0 records these same two failing audio checks; their thresholds
remain unchanged and the failures remain recorded. Replay matches the existing
golden, the four-player Terrordome stress passes four minutes, and the boot soak
passes 3/3. Startup audits confirm three fast launches and one normal launch in
quick, and 19 fast launches and one normal launch in full.

Windows and Steam Deck were not play-tested for this change in this session.
The existing intermittent audio-queue limitation remains.

## Updating

Run the setup for your platform and update the existing installation. Setup
builds the game locally from your own dump and preserves player data.
