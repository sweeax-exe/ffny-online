# v0.10.6 — Improved Game Launcher

A redesigned launcher for Steam Deck, Windows and macOS, with a focused Home screen
and organized Advanced settings. **v0.10.6 is the stable/latest release**.
First published as a beta on October 20, 2026, then promoted with the owner's approval
the same day. The tag and all nine verified setup/checksum/provenance assets are unchanged.

## Changes

- **Home plus Advanced settings.** Common display options and a large Play button on
  Home; Display, Controls, Mods, Interface, Diagnostics and Maintenance in Advanced.
  Charcoal, ivory, oxblood and gold, with quiet procedural brickwork and torn paper.
- **Direct utilities.** Advanced, Mods, Open Logs, Open Folder and Update / Repair.
  Mods lists local texture packs and their priority. Setup opens its existing wizard
  with installed paths prefilled; it does not begin an update automatically.
- **Clearer controls.** Brighter slider tracks, contextual explanations and a layout
  checked at 100–250% text, including small windows. Render-scale guidance explains
  internal resolution: 1× = 480p, 2× = 960p, 3× = 1440p, 4× = 1920p.
- **Fresh/reset defaults:** Windowed, 1920×1080, Widescreen (Auto), render scale 2,
  VSync on. Existing saved choices survive the update. Auto follows the monitor's
  shape; window resolution and internal render resolution are separate.
- Includes the v0.10.4 macOS setup quarantine fix and v0.10.5 skipped-startup menu-audio fix.

## Updating on Steam Deck

1. In Desktop Mode, download and extract **DefJamSetup-0.10.6-linux-x64.tar.gz**
   from this release, then run **DefJamSetup.sh** (choose Execute in Dolphin).
2. Select the existing install and data folders, choose **Clean Update**, and leave the
   release selector on **Bundled** so setup installs v0.10.6. Keep the Deck awake
   while setup rebuilds from your own supported dump. Player data is preserved.
3. Launch the existing game shortcut. If the launcher was previously skipped,
   turn that preference off or start the game with `--launcher` to inspect it.
4. Check Home/Advanced navigation, Deck controls, scrolling/text size, Play, texture
   packs and the utility buttons. In Gaming Mode, check that the game fills the
   display as intended. Fullscreen with Widescreen (Auto), VSync on and 2× is a
   useful Deck pairing; keep 1× available for heavier scenes.

v0.10.6 is now available through the setup's **Latest** release selection as well.
Windows and macOS users can use their matching setup from this release to update
the existing installation; saved preferences and player data are preserved.
