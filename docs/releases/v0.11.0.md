# v0.11.0 Preview — Widescreen menus and mod manager

This preview brings the widescreen menu pack into the launcher: discover it,
download it, enable it and choose override priority without extracting a ZIP.
Windows setup and native playtesting have been completed. Final Mac/Linux
playtesting is pending with the owner. Known visual issues below are accepted
for this preview; this is not a stable release.

## What changed

- **Signed mod catalogue and downloads.** Mods verifies the catalogue and pack
  hashes, supports testing versions, and keeps installed mods available offline.
  The separate HD Widescreen Menus pack supplies restored scenery, title/emblems
  and pre-fight backgrounds across 4:3, 16:10, 16:9, 21:9 and 32:9 where covered.
- **Clearer installed mods and priority.** Installed mods use a table. The two
  generated HD components appear as one **Recomp HD textures** row with details;
  existing folders/settings stay compatible. Load Order shows highest priority
  first: top rows override those below. Catalogue authors appear below the title.
- **Windows fixes.** Corrected the bundled helper's isolated Python imports and
  transient file-sharing failures during download progress updates. Added an
  actual embedded-helper packaging smoke check.
- **Platform compatibility.** Retains Windows startup/link fixes and merges the
  CachyOS C++20/Unicode path correction from #90. macOS setup gets deterministic
  disk-image headroom. No new toolkit/lifter/gameplay change in this release step.

## Installing and trying the menu pack

Download the setup for your platform from this preview release:

- Windows x64: `DefJamSetup-0.11.0-windows-x64.exe`
- macOS Apple Silicon: `DefJamSetup-0.11.0-macos-arm64.dmg` (unsigned)
- Linux x64 / Steam Deck: `DefJamSetup-0.11.0-linux-x64.tar.gz`

Choose **Bundled release (offline)** so setup builds this exact preview from
your own supported dump. For an existing installation, use Clean Update; a
separate preview installation/data folder is recommended for testing. Saves,
settings and existing packs are preserved by the update path.

In the launcher open **Mods → Refresh catalogue → Show testing versions**.
Download **HD Widescreen Menus 1.0.0-rc2**, enable HD textures and the pack, and
give it higher priority than generated textures in Load Order. Click **Play**.
Recomp HD is generated locally from your own dump; the menu pack is independent.
No Cloudflare account or manual archive extraction is needed.

GitHub marks this release as a prerelease. The setup's stable release picker
does not offer previews automatically; download these preview installers directly
and choose their bundled source. v0.10.7 remains the latest stable release.

## Accepted known issues

- **Paused HUD anchoring ([#95](https://github.com/vyanhursky/DefJamFFNY-recomp/issues/95)).**
  Opening pause during a widescreen fight can move fighter health/Blazin bars,
  names and scores inward to centered 4:3 positions.
- **Fire-escape pan.** A brief black rectangle above the first left scenery
  tile remains in the title-to-main-menu transition, including without mods.
- **Three uncovered backgrounds.** Select User ID, Choose Teams and Choose Venue
  remain on original backgrounds/side fill. Their widescreen artwork is deferred
  to modpack 1.1; it is not part of this preview.
- **Mac/Linux validation.** The owner will playtest the final shared UI and game
  on those platforms. Large-text/compact UI and every Story/multiplayer consumer
  have not been exhaustively verified. Other inherited limits remain in
  [known issues](https://github.com/vyanhursky/DefJamFFNY-recomp/blob/v0.11.0/docs/known-issues.md).

## Validation

Windows MSVC native build and 625 fast unit tests pass (26 platform skips, one slow
test deselected); 74 focused native/manager checks cover grouped components,
priority round-trips and C++17/C++20 Unicode paths. Real catalogue download,
installation, enablement/order, offline reopening, Play and native overlay pass.
The owner reviewed and accepted the revised Windows Mods layout.

Prior Windows gameplay validation satisfies 13 applicable checks across the full
run and a corrected loading-golden fixture retry, with four explicit SDL/Vulkan
skips. The initial nonzero full-run result is retained; the historical Mac 15/18
result and its failures are not relabeled as passes. Native captures inspect
five aspect ratios and all eight Mode selections. Original user saves/settings
were byte-identical after testing.

Only game-free setup tools, SHA-256 checksums and source/toolkit provenance are
attached. No game executable, generated guest code, game data or mod artwork is
included. Setup compiles the game locally from your own copy; artwork downloads
remain separate.
