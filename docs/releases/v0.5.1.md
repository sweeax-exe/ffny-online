# v0.5.1 — Windows release setup

This release adds a Windows x64 setup tool that builds the game locally from
your own supported USA Xbox dump. Game and renderer behavior remains that of
v0.5.0. No precompiled game, dump or generated guest code is distributed.

## Changes

- Native setup wizard with separate installation and data locations, ISO/XISO or
  extracted-folder input, silent mode, stage progress, cancellation and repair.
- Embedded Python, pinned source/toolkit and offline SDL3/ImGui build inputs.
  Setup verifies the payload and dump before local analysis, lifting and compilation.
  Missing Microsoft Build Tools installation requires explicit opt-in and consent.
- Optional desktop shortcut, Start-menu shortcut and an explicit completion path.
  Select Play or double-click `DefJamLauncher.exe` in the installation folder.
  The launcher supplies the correct data location and working directory.
- Versioned builds and certified stage reuse preserve saves/settings across updates.
  Removal preserves the dump, data, saves/settings, logs and compiler installation.
- Responsive background payload preparation, corrected Unicode window title, and
  persistent logs even for errors before installation starts. Open logs opens the
  current session file directly; failure dialogs show its location.
- Tagged-release CI inventories the game-free setup and creates a draft containing
  exactly the setup executable, SHA-256 checksum and provenance. Source policy
  continues to forbid game binaries, generated code and game data.

## Try setup

Run `DefJamSetup-0.5.1-windows-x64.exe`. Choose your dump and sibling folders such
as `D:\Games\DefJam\App` and `D:\Games\DefJam\Data`; data cannot be inside the
installation folder. Keep 12 GiB build headroom plus dump-copy and compiler space.
First setup can take substantial time to compile locally.

After completion, select Play, use a shortcut, or double-click
`D:\Games\DefJam\App\DefJamLauncher.exe`. Data and saves live in the chosen data
folder. Close the game and rerun setup with the same locations to repair/update.

Silent mode supports `--no-desktop-shortcut` (Start-menu only) and `--no-shortcuts`
(neither shortcut). Packaged logs default to `%LOCALAPPDATA%\DefJamSetup\logs`;
`--log` overrides the location. See [installer guide](../setup-installer.md).

The setup is unsigned. Signing/SmartScreen treatment and clean Windows 11/VS 2022
provisioning remain acceptance gates before public binary distribution.

## Validation and limits

- 216 project unit tests pass with MSVC, including 43 installer fixtures covering
  payload integrity, extraction, failed/cancelled stages, locks, destination rules,
  desktop choice, early logs and preservation behavior.
- Native title/control smoke and actual hidden-wizard payload preparation pass;
  the latter verifies UI events continue during preparation and early failure is logged.
- Packaged silent installation, source-commit update and same-release repair pass.
  Save/settings fixtures remain byte-identical; repair reuses the certified executable.
- Installed loading/title/menu golden checks and a scripted fight pass, with median
  120 presents per two seconds. The owner also completed a wizard install from XISO;
  that does not yet establish physical-machine gameplay acceptance for setup.
- Clean-machine provisioning, VS 2022/restart behavior, Unicode paths, changed-toolkit
  updates and signing remain to be validated. No new gameplay/renderer implementation
  is included. Toolkit pin remains `8f08c4f99b7b6e8401033fe43a6be09e5679f5c4`.
- Native macOS and Linux/Steam Deck setup artifacts remain to-dos. Their source build
  instructions and v0.5.0 platform validation limits still apply.

The SHA-256 and provenance assets identify the exact tagged source and toolkit used
by the setup. Hosted CI never receives a dump or builds a game executable.
