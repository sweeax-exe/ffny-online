# v1.0.0 beta 1 — Def Jam Recompiled, the app

**This is a beta for play-testers.** It is published as a GitHub prerelease, so it is not the latest release, and the app and setup of v0.13.0 never offer it as an update. The latest stable release stays [v0.13.0](v0.13.0.md). Please play it and [report what you find](https://github.com/vyanhursky/DefJamFFNY-recomp/issues/new/choose); press **F9** in the game to save a bug bundle (a short recording and the logs) to attach.

As always, you need your own supported USA Xbox dump. The app checks it and builds the game on your computer. No game files or game executables are distributed.

## What's new since v0.13.0

**One app for everything (#125-#132, #179).** **Def Jam Recompiled** is a single game-free app per platform. It replaces the setup wizard, the play wrappers and the launcher inside the game:

- **First run** asks for your dump, the install and data folders, and a picture style: **Modern** (widescreen at 2x, recommended) or **Original**. Generating upscaled original textures is optional. An existing installation can be reused.
- **Home** has Play, Settings, Controls, Mods and Help, with Check for updates kept in view. Advanced settings keep every option, with clearer descriptions.
- **Mods** has Installed and Browse tabs.
- **Updates.** The app updates itself from GitHub releases. When your installed game is older than the app, it offers to update the game first. Update reuses the verified analysis of your current build, so it is faster (#126).
- **Repair, Clean Rebuild and Uninstall** are under Advanced > Maintenance. Uninstall removes the app and its game builds and keeps your data folder (dump, saves, settings, mods and logs).
- Controller-only use, TV and high-DPI layouts are supported. On Windows the window is resizable and DPI-aware.

**Platforms:**
- **Windows:** `DefJamRecompiled-1.0.0-windows-x64.exe`. **Add to Steam** sits beside Play and adds the game with its library artwork (#144). The app makes no Start menu or desktop shortcuts.
- **Linux and Steam Deck:** `DefJamRecompiled-1.0.0-x86_64.AppImage`. It installs, updates and adds itself to Steam (#168). It builds the game with a toolchain it carries, so nothing has to be installed first, and SteamOS no longer downloads a ~1 GB container (#170).
- **macOS (Apple Silicon):** `DefJamRecompiled-1.0.0-macos-arm64.zip`. Steam integration is not available on macOS.
- The `DefJamSetup-1.0.0-*` setup tools are attached as well.

**Graphics options (#151).** Game texture levels, anisotropic filtering, MSAA anti-aliasing, high-quality downscaling, a colour tint and film scratches. Every one defaults to the picture as it was, and existing installations keep their settings.

**Cheats (#97).** Infinite health, max Blazin', no regeneration, Story cash and development points, giant and tiny fighters, and fighter swaps. Cheats that change your Story profile ask first and are permanent.

**Fixes:**
- The SC04 cutscene's picture no longer runs ahead of its audio (#164, issue #161).
- The uninstall log now records what was removed and what was kept.

## Tested before this beta

- **Windows 11:** a fresh analysis, lift and release build, then the full regression in two lanes. The stock lane passed 16 of 17 checks, and so did the 16:9 lane with HD Widescreen Menus 1.4.0 and HD Fighters 1.0. The one failure was a test-only check, fixed since. Cheats and the graphics options were also tested in fights and Story. Scratch installs covered installing, a Clean Update from v0.13.0, Repair, an interrupted Clean Rebuild, Uninstall and Add to Steam (on a test Steam folder).
- **Steam Deck:** the full regression passed its gameplay checks. Its menu-script checks were updated for the new launcher layout afterwards.
- **macOS:** regression run by the owner's macOS agent.
- **CI:** all three app and setup builds pass, along with the unit tests, native fixtures and source policy.

## Known issues

- **Updating from a beta.** The app offers only newer stable releases. This beta reports version 1.0.0, so it will not offer a later beta or the final 1.0.0 to you. Download those from the [releases page](https://github.com/vyanhursky/DefJamFFNY-recomp/releases) and the app updates the existing installation.
- **Learn Moves.** The Story Learn Moves list now draws grey and light bars behind its rows (#181), which may or may not match the console.
- **Disk space.** Each Update or Repair keeps another ~600 MB build in the install folder (#180).
- **Under investigation:** memory growth over long sessions (#166), plain fight replays that differ on the Steam Deck (#98), and the menu and map issues #141 and #162.
- The project website (#133) is not part of this release.

See [the regression plan for v1.0.0](../regression-v1.0.0.md) for every included change, its commit and the platform test commands.
