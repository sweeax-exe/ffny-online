# v0.13.0 — Language, audio and controller input (release candidate)

This candidate combines PR #156 (audio heap/window separation), #153 (language
mods, the disc's French interface and English Story subtitles) and #158 (ordered
controller transitions and software input tracing). It is awaiting platform
regressions, setup acceptance and the owner's combined-candidate playtest.

- Heap RAM uses its first-mirror physical alias, preventing music/speech buffers
  from reading a different heap page after a language pack changes its layout.
- Language mods contain deltas against the player's dump, rebuilt into a cache;
  they do not modify the dump. One language mod is selected independently of
  texture-pack order. No translated pack is distributed with this release.
- Interface offers the game's built-in French and Story subtitles in every
  cutscene, including English. French voices and icon artwork remain English;
  the disc has untranslated entries, including 69 gym tips.
- Rapid controller presses retain ordered transitions through guest consumption.
  Host acquisition targets 1 ms. Optional late refresh remains off by default;
  software tracing measures delivery/consumption, not physical display latency.
- macOS setup CI uses macos-15. Windows, Apple Silicon macOS, and x86-64 Linux
  retain their existing source/local-build setup model and SDL controller support.

Toolkit: `d569ca1` on `defjam/release-0.13.0`: base `be83eb9` plus `7d98332`
(audio), `efde320` (redirect, cherry-picked as `2a84422`) and `b7db8c1`
(input, cherry-picked as `d569ca1`). New guest wrappers require a fresh lift.

The candidate gate uses 16:9 with HD Widescreen Menus **1.4.0** and HD Fighters
**1.0.0**, installed and digest-verified through the signed catalogue. The full
suite adds French-interface captures, English sc05 subtitle captures and traced
20 ms controller presses with late refresh off/on. Original-image goldens remain
a separate stock 4:3 compatibility lane; they are never regenerated to bless mods.

See [candidate test commands](../regression-v0.13.0.md) and the release PR for
current results. Capture review is a separate gate from checking the language
table and subtitle-enable state. Existing limits, including Deck determinism
issue #98, remain in [known issues](../known-issues.md); PR #146 is excluded.

No release tag or public release has been created. Only source and game-free
setup tools may be published after the candidate gates pass.
