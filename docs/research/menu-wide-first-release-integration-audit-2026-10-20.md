## Extension workflow

`config/menu-ui-wide-layers.json` is the current registration table. Each row identifies the anchor source ID, approved master path, `per` (native title pixels per source texel), settled `x0`, and side policy. `match_u` excludes source columns obscured by foreground art while locating the tile in the master; `u_range` is the sampled source interval used to step repeated slabs; `inner` replaces the 4:3 anchor in widescreen where the art requires it. The exporter verifies master SHA-256 against `config/menu-ui-approved-artwork.json`, locates the corresponding tile in the first matching anchor pack, checks match confidence, and emits immutable `manifest.ini`, PNG slabs and a receipt. Use a new component name/output folder for each revision.

For a new full-screen layer, first establish the exact source ID and aliases from the user's own dump, complete native dimensions/UV and alpha identity, and whether a multi-piece composition shares one transform. Register reviewed art by hash in the approval catalogue and add its source-shaped tile to `config/menu-ui-source-shaped-exports.json`; the wide exporter obtains its replacement tile from the anchor packs named by `anchor_packs`. Then add a layer row with the approved master, native texel-to-screen scale, settled anchor origin, side policy and exact sampled U interval. For multi-piece backgrounds, treat each source as its own anchor against the same master, retaining its own x origin, UV interval, and obscured match columns. Do not assume that a local APT bound is the screen transform.

Before calling the result accepted, capture the native screen at 4:3, 16:10, 16:9, 21:9 and 32:9, including every moving/lighting state. Confirm the master center registration, seam/side joins, source UV mapping, clip/scissor edges, alpha, scroll or pan endpoints, transitions and fade behavior. The existing toolkit fixture covers manifest parsing, slab ordering/binding, malformed entries, inner replacement and stretch overlays (`tools/xboxrecomp/tests/texture_pack/test_main.c`); it does not prove a new game's APT transform or screen behavior. Add a focused fixture when adding runtime semantics, then perform serial native game checks. Current gap metadata explicitly lacks root placement, parent transforms, clipping, motion and runtime texture use.
