# Xbox 360 recomp input survey: Xenon and ReXGlue projects

Source audit snapshot recorded 2026-10-30. Five separate Xbox 360 games are covered. The findings distinguish each game's call path from shared SDK code: two use the XenonRecomp family, two use ReXGlue, and MW2 has a separate runtime, so the five rows do not represent five independent controller backends. Source repositories were fetched shallowly (no game data, no build, no game run) into `logs/input-audit/research/xenon/`. Exact commit SHAs and dates are recorded per project. GitHub links use those SHAs for stable citations.

## Project selection and independence

The assigned Sonic ’06 candidate was replaced by Sonic Free Riders. The surfaced `NaGaa95/MarathonRecomp-NX` says it is a static recomp of Sonic ’06 but appears to be a platform-specific mirror/fork; I did not establish an inspectable originating gameplay input implementation in this bounded audit. Free Riders is a verified, distinct Xbox 360 static recomp with a source-readable native input layer.

The GoldenEye project here is the cancelled XBLA version, not the separate 2011 *GoldenEye 007: Reloaded* recomp. Skate 3's ReXGlue runtime was pinned and inspected; GoldenEye's was not pinned in its source snapshot. Unleashed implements its own SDL HID driver. MW2 has a separate SDL3 runtime. Free Riders implements its own host-native input layer on top of XInput/SDL. These systems are therefore only partially independent.

## Latency evidence boundary

No project in this five-game sample supplies a measured input-to-photon latency figure that was independently validated here. Unleashed explicitly places swap-chain waiting before its input sampling and describes the technique as latency reduction, which is source-backed design intent. Skate's debug probe says absent-slot XInput queries are slow and backs off; that's not gameplay behavior. The other observed frame caps, packet counters, or responsiveness claims do not establish latency. A comparison would need timestamped physical input, guest state observation, render submission, and display/photodiode or equivalent presentation measurement.
